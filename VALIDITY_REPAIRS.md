These corrections are proposals for a new evaluation version. Original runs and scores are not reinterpreted or overwritten. A passing software test does not qualify a task for a model comparison.

- **Judge inputs `score_only_goals_v2`:** phase two receives the exact initial instruction in place of the authoring README, and a rubric projection containing only unchanged goal IDs, descriptions, tiers and weights. Rationale/decomposition/history fields remain in source assets but are not staged. Verdicts record the input protocol; old verdict files are preserved. The prompt distinguishes runtime evidence from author assumptions and syntax/proportional gates, and requests an error without a score when infrastructure prevents required verification. The source simulator brief and test files remain available, so this is not a guarantee that every task input is clean or every goal was delivered. Task/reference defects and matched-turn qualification remain separate blockers. No original score is revised.
- **Simulator 0.11.1:** preserve substantive text beside tool results and inside rejected edits; exclude context-continuation boilerplate; recognize whole silence markers rather than suppressing any message mentioning “silent”; hide fallback diagnostics from delivered history. Both launchers share the guidance that removes message quotas and requires the original trigger. This prompt guidance does not enforce semantic grounding.
- **CLI b3d2dd:** restore the source user's referenced plan through a declared prerequisite manifest and restore the omitted UUID-filtering correction. This task remains unsuitable for comparison until its bug-3 request and bug-1 rubric are reconciled. The native adapter stages and captures the declared file; upstream reproduction runners need equivalent staging before using this variant.
- **CLI c01017:** restore three omitted human corrections in the simulator brief and distinguish its 22 substantive text messages from tool scaffolding.
- **CLI 70c88c, task/verifier 2.0:** replace a name-bound Go-test check with observable CLI behavior, including a positional argument with qualifier flags; correct intent provenance. Setup errors and timeouts raise without a numeric reward. The invalid fixed after-turn contract is removed: the source branch correction rejected an Edit before it wrote, so after-turn delivery is not equivalent. Go build/test failures still require log attribution before any comparison; this checker is not an infrastructure classifier.
- **Lumina2 LoRA, task/verifier 2.0 and rubric/4.0:** [repair notes](tasks/comfyui-lumina2-lora-prefix/repair_notes.md) document the exact-example check, real weight loading, separate corrected reference, and task-local removal of historical outcomes from judge inputs. This branch does not establish a repaired aggregate ranking.
